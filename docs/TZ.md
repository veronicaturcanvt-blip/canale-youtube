# Приложение йоги/пилатес — техническое задание для разработки

## О проекте
Мобильное приложение для практик йоги и пилатеса, привязанное к AI-аватару
(персональный тренер). Целевая аудитория: люди без времени/доступа к
спортзалу или те, кто много путешествует. Вдохновение: Down Dog, Fitbod,
Gymverse. MVP не включает советы по питанию.

## Дизайн
Цветовая палитра "природа":
- Основной: зелёный шалфей
- Вторичный: светло-голубой (аква)
- Акцент: жёлтый горчичный

Есть готовые чёрновые мокапы трёх экранов (главный, поиск/фильтры,
подписка) — приложены отдельно как референс визуальной структуры.

## Технические требования
- Видео: стриминг HLS/DASH с DRM (Widevine/FairPlay), без скачивания
  оригинальных файлов
- Доступ к профилю и видео только при активной подписке
- Оплата/подписка: App Store + Google Play, с учётом DMA-опции внешней
  оплаты для ЕС
- Соответствие GDPR: политика конфиденциальности, cookies, удаление
  данных по запросу
- Бэкенд: логин, база данных, видео-CDN, push-уведомления
- Мультиязычность: IT/EN/RU/ES/ZH/JA
- Номера карт не хранятся напрямую — оплата через Stripe/App
  Store/Google Play billing (токенизация)

## Фичи MVP

**Онбординг** — выбор времени (5/15/30/45 мин) и инвентаря (без
инвентаря/коврик/реформер)

**Генерация практики** — библиотека готовых практик, фильтруемая по
времени и инвентарю (без динамической сборки из блоков)

**Поиск и фильтры** — тип практики (йога/пилатес), длительность,
инвентарь, уровень сложности, зона тела, интенсивность/настроение

**Подписка**
- Пейволл сразу после онбординга
- Пробный период: 3 дня
- Тариф: годовой, framing "2 месяца бесплатно"
- Экран включает: цены, кнопку "восстановить покупки", список того,
  что даёт подписка (безлимит практик, все уровни)
- Продление через год: скидка 30%, дешевле цены для новых подписчиков

**Профиль**
- Статистика (общее время, количество занятий)
- Избранное (сохранённые практики)
- Данные абонемента: дата подписки, тариф, дата окончания, стоимость
- Пауза подписки на 1 месяц без оплаты
- Личные данные: имя, фамилия, email, дата рождения, страна
- Смена способа оплаты при неудачном списании
- Смена входного PIN-кода
- Кнопка выхода из аккаунта

**Вход** — через аккаунт ИЛИ через PIN-код как альтернатива

**Приглашение друга** — реферальная ссылка; пригласивший получает
3 месяца бесплатно, приглашённый — расширенный пробный период (7 дней
вместо 3)

**Геймификация** — бейджи/достижения на основе streak (дней подряд),
возможность делиться достижениями в соцсетях

**UI-деталь** — уже пройденные практики визуально выделяются другим
цветом в списках

# Memovita — тестовая версия (web-приложение)

**Memovita: la tua vita, senza dimenticare niente.**
Приложение для повседневных дел: сроки, документы, чеки и списки покупок в одном месте.
Интерфейс на итальянском.

Опубликовано: https://veronicaturcanvt-blip.github.io/canale-youtube/memovita/

## Файлы

- `index.html` — всё приложение в одном файле (HTML + CSS + JS), сборка не нужна.
- `manifest.webmanifest` и `icons/` — чтобы приложение можно было добавить на экран «Домой» телефона со своей иконкой.

Открыть локально: дважды кликнуть `index.html` или запустить `npx http-server -p 8080` из этой папки.

## Как публикуется

При пуше в ветку `claude/gifted-darwin-ui1rxp` (или в основную) workflow
`.github/workflows/publish-portfolio.yml` копирует эту папку в `gh-pages/memovita/`,
а `portfolio/` — в корень сайта.

## Где хранятся данные

Всё хранится только на телефоне пользователя: данные в `localStorage` (ключ `memovita:v1`),
фото и PDF в IndexedDB (`memovita`). Сервера нет, никто кроме пользователя данные не видит.
Резервная копия: Profilo → Esporta / Importa backup (JSON-файл).

## Что уже есть

- Главный экран: красный колокольчик, календарь недели с сезонной темой месяца, «In arrivo», цветные плитки разделов (Casa шалфей, Macchina синий; красный цвет только для колокольчика).
- Онбординг: круг из иконок разделов, в центре всегда сегодняшняя дата.
- Разделы и подразделы: создать, переименовать, цвет, иконка, удалить, скрыть с главного экрана.
- Сроки: дата, сумма, повтор (неделя с выбором дней без даты, месяц, 2/3/6 месяцев, год, 2 года), заметки, «Segna come pagato» сам создаёт следующий срок.
- Напоминания: несколько сразу (1 год, 6 месяцев, 3 месяца, 30 дней, 7 дней, 1 день) + всегда в день срока. Срок появляется в «In arrivo» и на колокольчике только когда сработало выбранное напоминание; «Ho visto l'avviso» гасит его до следующего.
- Документы: фото, скриншоты и PDF (можно несколько сразу), просмотр, переименование, сохранение.
- Календарь месяца, поиск (разделы, сроки, заметки, документы, списки покупок), страница уведомлений.
- Da fare: плитка для быстрых мыслей и дел; напоминание «сегодня» (18:00 или через час), «завтра» (9:00) или своя дата и время; колокольчик, бейдж на плитке, «In arrivo», точка в календаре, кнопка «добавить в календарь телефона»; можно скрыть в Profilo.
- Spesa: несколько списков (Supermercato, Farmacia, Casa + свои), отметка одним касанием, автоматические отделы магазина, «I soliti».
- Privacy простыми словами.

## Решения на будущее (версия 2, нативное приложение)

- Всё, что использует ИИ (сканирование документов, сроки из email, чтение текста в фото/PDF), — платно. Остальное бесплатно, и то, что бесплатно, не забираем.
- Вход по email с кодом (без пароля).
- Общий доступ для семьи для всего приложения: уведомление после изменения («Veronica ha spostato il Bollo al 15 dicembre»). Нужен сервер в ЕС, шифрование, GDPR.
- Настоящие push-уведомления и виджет на экран телефона — только в нативной версии.
- Отказались: «кладовая» со сроками годности продуктов (слишком много усилий для пользователя).
